# תוכנית מבנה דפים – DarkPool

## הבעיה

> "זה מרגיש המון דברים נפרדים בלי קשר אחד לשני, בלי מבנה של דפים עם בשר וכו׳"

**מצב נוכחי:**
- כל מסך בונה את עצמו מאפס: כותרת → טאבים → תוכן
- אין קומפוננטת `ScreenLayout` או `PageLayout` משותפת
- התוכן = כרטיסים מונחים אחד מעל השני (UICard)
- אין היררכיה ברורה: **דף → סקשנים → תוכן**
- WebViews (TradingView) מרגישים כמו "חלון" מנותק בתוך המסך
- אין "בשר" – אין הרגשה של דף עם כותרת מרכזית, סקשנים, קשר לוגי בין חלקים

---

## הפתרון המוצע: מבנה דף אחיד

### 1. קומפוננטת `ScreenLayout` / `PageLayout`

**מבנה מוצע:**
```
ScreenLayout
├── hero (אופציונלי)     – כותרת גדולה + תיאור
├── nav/tabs (אופציונלי)  – ניווט פנימי
├── sections[]            – סקשנים עם כותרות
│   ├── Section: "מדדים ועתידיים"
│   │   └── content (WebView / רשימה / כרטיסים)
│   ├── Section: "נתונים נוספים"
│   │   └── content
│   └── ...
└── footer (אופציונלי)
```

**יתרונות:**
- אותה "שלד" בכל מסך – עקביות
- סקשנים יוצרים קשר ויזואלי בין חלקים (כותרת סקשן + תוכן)
- אפשר להוסיף "בשר" – תיאורים קצרים, קישורים, CTAs בתוך סקשנים

### 2. סקשנים במקום כרטיסים בודדים

| לפני | אחרי |
|------|------|
| UICard(header) + UICard(tabs) + UICard(widget) | ScreenLayout → Section("מדדים") → WebView |
| כל כרטיס = יחידה נפרדת | סקשן מקשר כותרת + תוכן |

### 3. חיבור תוכן

- **כותרת סקשן** – מסבירה מה יש מתחת
- **תיאור קצר** (אופציונלי) – "סקירה מקיפה של המדדים העיקריים"
- **קישורים** – "למד עוד" / "היסטוריה" – מחברים בין חלקי האפליקציה

---

## דוגמה: מסך שווקים

**היום:**
```
[כרטיס: שווקים / סקירה מקיפה...]
[כרטיס: מפות חום | מדד הפחד | מדדים]
[כרטיס: מדדים ועתידיים]
  [WebView - TradingView]
```

**אחרי:**
```
PageLayout
  hero: "שווקים" / "סקירה מקיפה של השווקים הפיננסיים"
  nav: [מפות חום | מדד הפחד | מדדים]

  Section("מדדים ועתידיים", description="המדדים העיקריים - S&P500, Nasdaq, Dow")
    → WebView / רשימה

  Section("מדד הפחד והחמדנות")  // כשטאב פעיל
    → FearAndGreedCard

  Section("מפות חום")
    → sub-nav + WebView
```

## שלבי יישום

1. **יצירת `ScreenLayout`** – קומפוננטה עם props: `hero`, `tabs`, `sections`, `children`
2. **מיגרציה** – MarketsScreen, NewsScreen, Journal – מעבר ל-ScreenLayout
3. **סקשנים** – הוספת `Section` עם כותרת + תיאור אופציונלי
4. **פוליש** – מרווחים, אנימציות עדינות, קישורים בין סקשנים
