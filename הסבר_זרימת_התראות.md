# 📱 הסבר זרימת התראות Push

## 🔄 איך זה עובד - שלב אחר שלב:

### שלב 1: חדשה נוספת ל-`app_news`
```
משתמש מוסיף חדשה → INSERT INTO app_news
```

### שלב 2: Trigger מזהה את ה-INSERT
```
Trigger: on_new_news_article
↓
קורא ל: send_news_notification_immediately()
```

### שלב 3: הפונקציה SQL `send_news_notification_immediately()` עושה 2 דברים:

#### א. שולחת HTTP request ל-Edge Function (מיידי)
```
pg_net.http_post → 
  Edge Function: process-pending-notifications
```

#### ב. שומרת התראות ב-`pending_notifications` (גיבוי)
```
INSERT INTO pending_notifications
  (user_id, title, body, notification_type, ...)
```

### שלב 4: ה-Edge Function `process-pending-notifications` עושה:

1. **קוראת** את ההתראות מ-`pending_notifications`:
   ```sql
   SELECT * FROM pending_notifications 
   WHERE is_sent = false
   ```

2. **בודקת** את ההגדרות של המשתמש:
   - האם המשתמש רוצה התראות חדשות?
   - האם המשתמש רוצה התראות בכלל?

3. **שולחת** את ההתראות דרך Expo Push API:
   ```
   POST https://exp.host/--/api/v2/push/send
   ```

4. **מסמנת** את ההתראות כנשלחו:
   ```sql
   UPDATE pending_notifications 
   SET is_sent = true, sent_at = NOW()
   ```

---

## 📋 סיכום - מה כל פונקציה עושה:

### 1. `send_news_notification_immediately()` (SQL Function)
- **מה זה:** פונקציה SQL שרצה ב-trigger
- **מה היא עושה:**
  - שולחת HTTP request ל-Edge Function (אם pg_net עובד)
  - שומרת התראות ב-`pending_notifications`
- **איפה:** במסד הנתונים (PostgreSQL)

### 2. `process-pending-notifications` (Edge Function)
- **מה זה:** Edge Function ב-Deno
- **מה היא עושה:**
  - קוראת התראות מ-`pending_notifications`
  - בודקת הגדרות משתמש
  - שולחת התראות דרך Expo Push API
- **איפה:** ב-Supabase Edge Functions

## ✅ אז מה צריך לעשות?

### 1. הפונקציה SQL (`send_news_notification_immediately`)
- **קובץ:** `פונקציה_תקינה_התראות_חדשות.sql`
- **מה זה עושה:** יוצר את הפונקציה וה-trigger
- **איך להריץ:** ב-Supabase SQL Editor

### 2. ה-Edge Function (`process-pending-notifications`)
- **קובץ:** `supabase/functions/process-pending-notifications/index.ts`
- **מה זה עושה:** קוראת מ-`pending_notifications` ושולחת התראות
- **איך להריץ:** 
  ```bash
  supabase functions deploy process-pending-notifications
  ```

## 🔍 איך לבדוק שהכל עובד:

### בדיקה 1: האם הפונקציה SQL קיימת?
```sql
SELECT proname 
FROM pg_proc 
WHERE proname = 'send_news_notification_immediately';
```

### בדיקה 2: האם ה-trigger קיים?
```sql
SELECT trigger_name 
FROM information_schema.triggers 
WHERE trigger_name = 'on_new_news_article';
```

### בדיקה 3: האם ה-Edge Function קיימת?
- לך ל: Supabase Dashboard > Edge Functions
- בדוק אם `process-pending-notifications` קיימת

### בדיקה 4: האם התראות נשמרות ב-`pending_notifications`?
```sql
SELECT * FROM pending_notifications 
ORDER BY created_at DESC 
LIMIT 5;
```

### בדיקה 5: האם ה-Edge Function נקראה?
- לך ל: Supabase Dashboard > Edge Functions > `process-pending-notifications` > Logs
- אמור לראות קריאות ל-Function
