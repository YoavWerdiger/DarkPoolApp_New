# תוכנית שיפור UI – DarkPool

## סקירה – מה קיים היום

### 1. טאב בר (MainTabs)
- **רקע:** GlassView (iOS 26) / גרדיאנט (fallback)
- **סגנון:** מעוגל למעלה (2xl), צל, transparent
- **אייקונים:** Lottie (focused) + SVG (unfocused)

### 2. כרטיסים (UICard)
- **ברירת מחדל:** `variant="blur"` = BlurView + overlay + border
- **בעיה ידועה:** על רקע כהה הכרטיסים נראים מוצקים/כהה

### 3. צבעים (DesignTokens)
- **Primary:** #00C805 (Robinhood green)
- **Background:** #0D1210, #131A18, #1A2320, #111111, #1A1A1A
- **Text:** לבן + rgba ל� secondary/tertiary

### 4. טיפוגרפיה (DesignTokens)
- **גופנים:** system, Assistant, mono
- **גדלים:** xs(11) → 5xl(48)
- **משקלים:** light → black

## תוכנית שיפור – 4 שלבים

### שלב 1: פישוט – "נקי ומוצק"
**מטרה:** עיצוב אחיד, פחות layers, פחות blur שלא נראה.

| רכיב | שינוי מוצע |
|------|-----------|
| **UICard** | ברירת מחדל → `elevated` (רקע #1A1A1A מוצק) |
| **טאב בר** | רקע מוצק #1A1A1A בלבד – בלי Glass, בלי גרדיאנט |
| **רקע מסכים** | גרדיאנט דף כניסה נשאר |

### שלב 2: צבעים – ניגודיות
**מטרה:** הבחנה טובה יותר בין רמות.

| רכיב | שינוי מוצע |
|------|-----------|
| **כרטיסים** | רקע #1C1C1E (קצת בהיר מ-background) |
| **טאב בר** | אותו צבע – עקביות |
| **טקסט משני** | rgba(255,255,255,0.72) – קריא יותר |

### שלב 3: טיפוגרפיה – היררכיה
**מטרה:** כותרות בולטות, גוף טקסט קריא.

| רכיב | שינוי מוצע |
|------|-----------|
| **כותרות מסך** | 20px, semibold, letterSpacing: -0.3 |
| **גוף טקסט** | 15px, lineHeight: 1.5 |
| **תוויות** | 13px, medium |

### שלב 4: טאב בר – פוליש סופי
**מטרה:** מראה מודרני ונקי.

| רכיב | שינוי מוצע |
|------|-----------|
| **מרווחים** | padding מאוזן, פחות שטח ריק |
| **אייקונים** | גודל אחיד 24px |
| **תוויות** | 12px, משקל medium |
